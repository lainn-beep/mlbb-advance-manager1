MLBB ADVANCE MANAGER — PWA

CARA PAKAI:
1. Ekstrak ZIP.
2. Upload ISI folder ini ke hosting statis HTTPS, misalnya GitHub Pages.
3. Buka URL HTTPS di Chrome Android.
4. Menu ⋮ > Tambahkan ke layar utama / Install app.

GitHub Pages:
- Buat repository baru di GitHub.
- Upload semua isi folder ini ke root repository (jangan ZIP sebagai satu file).
- Settings > Pages > Deploy from a branch > main > /(root) > Save.
- Tunggu alamat HTTPS terbit, lalu buka di Chrome HP.

CATATAN:
- Membuka index.html dari file manager hanya untuk pratinjau; instalasi PWA memerlukan HTTPS/localhost.
- Data disimpan di localStorage browser. Backup JSON secara berkala; hapus data browser dapat menghapus data aplikasi.
- Jangan simpan password, OTP, cookie, atau token game.
- Aplikasi tidak resmi dan tidak terhubung ke server MLBB.
- Rasio coin/Diamond harus diisi berdasarkan angka resmi yang terlihat di game.
- Pengingat hanya daftar jadwal; tidak melakukan klaim otomatis dan notifikasi tidak dijamin saat aplikasi tertutup.
- Tidak ada pembuatan akun massal atau bot gameplay.
